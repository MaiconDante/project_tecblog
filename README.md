# 🌟 TecBlog

Projeto desenvolvido durante o curso **Desenvolvimento Web Completo** da Udemy, com o objetivo de consolidar conhecimentos em HTML5 e CSS3 por meio da criação de um blog temático voltado ao universo da tecnologia.

## 📷 Demonstração

**URL** -> <a href="https://maicondante.github.io/Projeto_TecBlog/">Projeto TecBlog</a>

---

## 📌 Sobre o Projeto

O TecBlog é um site fictício de tecnologia desenvolvido para praticar conceitos fundamentais de desenvolvimento web utilizando exclusivamente HTML5 e CSS3.

O projeto simula a estrutura de um blog moderno, contendo áreas de conteúdo, menu de navegação, barra lateral e rodapé, permitindo exercitar a organização visual e estrutural de páginas web sem o uso de JavaScript ou frameworks.

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* Folha de estilo externa (`style.css`)
* Tags semânticas para estruturação do conteúdo

---

## 🧠 Conceitos Trabalhados

Durante o desenvolvimento deste projeto foram aplicados conceitos como:

* Estruturação semântica de páginas com HTML5
* Separação entre conteúdo e apresentação
* Criação de layouts utilizando CSS3
* Organização de menus de navegação
* Construção de áreas de conteúdo principal e barra lateral
* Padronização visual entre páginas
* Boas práticas de organização de código HTML e CSS

---

## 🌐 Estrutura do Site

O site é composto por páginas temáticas relacionadas ao universo da tecnologia:

* 🏠 Home
* 🎮 Jogos
* 📱 Celulares
* 💻 Informática
* 🔌 Eletrônicos

Todas as páginas compartilham a mesma identidade visual e estrutura de navegação, proporcionando uma experiência consistente ao usuário.

---

## 🎯 Objetivos de Aprendizagem

Durante a construção do projeto foram desenvolvidas habilidades relacionadas a:

* Criação de blogs estáticos utilizando HTML e CSS
* Aplicação de semântica em páginas web
* Desenvolvimento de layouts organizados e reutilizáveis
* Estruturação de conteúdo para melhor legibilidade
* Utilização de CSS para estilização e identidade visual
* Organização de múltiplas páginas em um único projeto

1. Clone este repositório:
